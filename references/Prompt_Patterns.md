# Prompt Patterns

Select patterns according to task needs; combine sparingly.

- Direct instruction / zero-shot: best for simple, well-defined tasks.
- Role or perspective: use when a relevant professional lens changes the analysis; avoid grandiose role labels without purpose.
- Few-shot examples: use when format, style, or edge-case behavior is hard to explain abstractly.
- Decomposition: split complex work into stages with explicit inputs, outputs, dependencies, and checkpoints.
- Plan then execute: useful for multi-step work; ask for a concise plan or milestones when that improves control.
- Critique and revise: useful when quality can be checked against named criteria.
- Structured output: specify fields, sections, or a schema when downstream use requires consistency.
- Alternatives and comparison: ask for options and a decision criterion when choosing among plausible approaches.
- Reasoning summary: request key rationale, checks, or concise justification rather than hidden chain-of-thought.

A pattern is not a decoration. If a direct instruction is sufficient, keep it direct.
