# Reasoning and Multi-Step Task Guidance

For complex tasks, specify the outcome, relevant constraints, stages, and checks. Request concise reasoning summaries, assumptions, evidence, or verification steps when these help the user evaluate the answer.

Do not require disclosure of private internal chain-of-thought. Prefer user-facing explanations such as “summarize the key factors,” “show calculations,” “cite supporting evidence,” or “list assumptions and checks.” For arithmetic or code, ask for verifiable intermediate results or tests when useful.

For workflows, define dependencies and what should happen if a stage fails or input is missing. Keep simple tasks direct.
