# Prompt Rewrite Rules

1. Preserve intent: do not change the user's objective, audience, or desired deliverable without saying so.
2. Add precision, not bulk: every new instruction should resolve a real ambiguity or improve execution.
3. Do not invent facts: use placeholders or label assumptions for unknown names, data, budgets, dates, or context.
4. Keep constraints compatible: identify collisions and propose a transparent resolution.
5. Make the output actionable: specify format and success criteria when they matter.
6. Match complexity: simple prompts should stay simple; complex workflows need stages and dependencies.
7. Respect the target model: prefer durable capabilities over claims tied to a model version.
8. Explain important edits with a specific reason.
9. Preserve user voice when editing existing text unless a change in tone is requested.
10. Never optimize a harmful request into a more effective harmful request.

Tier guidance: Standard clarifies the task with minimal structure; Professional adds useful context, constraints, and output definition; Expert adds a robust workflow, checks, edge-case handling, or evaluation criteria only when justified. Tiers are not a contest in length.
