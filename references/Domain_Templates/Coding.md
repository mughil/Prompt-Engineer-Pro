# Coding Domain Template

Specify language, framework, runtime, repository context, desired behavior, constraints, and how success will be tested. For debugging, include the error, reproduction steps, expected behavior, actual behavior, and relevant logs or code.

Ask for a minimal safe change when the scope is uncertain. For repository edits, inspect existing conventions first, avoid unrelated changes, protect secrets, and run relevant tests. State any assumptions about versions or dependencies. Never claim tests passed unless they were run.
