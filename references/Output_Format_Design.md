# Output Format Design

Choose a format that supports the user's next action.

- Prose for explanations, narratives, or nuanced synthesis.
- Bullets for scan-friendly recommendations.
- Tables for direct comparisons across the same criteria.
- Numbered steps for ordered procedures.
- JSON or another schema only when software or downstream processing needs it; define required fields and valid values.
- Code blocks for copyable prompts, commands, or code.

Specify length, headings, examples, citations, or validation rules only when useful. If the format is strict, describe what to do when information is unknown. Do not request incompatible formats at once.
