# Model Optimization

Adapt to the target system's documented, general capabilities. Do not fabricate current model names, versions, limits, or performance rankings; verify time-sensitive claims with live sources when available.

- Claude and ChatGPT: clear instructions, relevant context, explicit deliverables, and well-bounded multi-step tasks are broadly useful.
- Gemini and other general assistants: state the task, source context, constraints, and expected output plainly; verify current product-specific features when relevant.
- Coding assistants such as Cursor or GitHub Copilot: include repository context, target files, constraints, expected behavior, tests, and acceptance criteria. Ask the tool to inspect before editing when scope is uncertain.
- Research/search tools such as Perplexity: define the research question, date range, source-quality expectations, and how evidence should be synthesized.
- Image-generation tools such as Midjourney: describe subject, composition, environment, lighting, visual style, aspect ratio, and exclusions. Avoid relying on unsupported syntax.

When no target model is named, use portable instructions. Do not claim a prompt will guarantee a particular result.
