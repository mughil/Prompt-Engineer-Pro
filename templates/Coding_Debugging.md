# Starter Template: Debugging

Use when: something is broken and you want a cause and a minimal fix, not a rewrite.

```
Debug this [language / framework] issue.

Expected behavior: [what should happen].
Actual behavior: [what happens instead].
Error message and logs: [paste the exact output].
Reproduction: [steps, or a minimal code sample that triggers it].
Environment: [versions, OS, relevant config].

First explain the most likely cause and how to confirm it. Then propose the minimal fix. Do not rewrite unrelated code.
```

How to use: paste the real error text, not a paraphrase - the exact wording is often the clue.
