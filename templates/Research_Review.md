# Starter Template: Evidence Review

Use when: mapping what is known (and contested) about a topic.

```
Summarize the current evidence on [topic] for [audience].

Cover: the main findings or positions, where sources agree and disagree, and how strong the evidence is for each claim.
Sources: [academic / industry / mixed], prioritizing [recency / authority].
Format: [e.g. a comparison table plus a one-page brief].

Flag explicitly where the evidence is thin, old, or contested.
```

How to use: "flag thin evidence" is doing the real work here - without it, reviews read as if every claim is equally settled.
