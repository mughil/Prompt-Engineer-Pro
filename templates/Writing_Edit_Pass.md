# Starter Template: Editing an Existing Draft

Use when: improving text you have already written.

```
Edit the text below. Preserve my meaning and my voice unless I ask you to change them.

Focus on: [clarity / structure / concision / tone for a specific audience].
Before editing, list the 3-5 highest-impact changes you plan to make and why.
Then return the full edited text. If anything is ambiguous, flag it rather than guessing.

Text:
[paste your draft]
```

How to use: name one focus, not all four - an edit that chases everything improves nothing. Ask for a review after filling if the stakes are high.
