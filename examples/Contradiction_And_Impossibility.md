# Worked Example: Contradictions and Impossibility

## Original prompt
“Write a detailed 2,000-word report in exactly 200 words.”

## Assessment
The length requirements conflict. This is impossible as written if both counts are exact.

## Better response
State the conflict and ask which constraint takes priority, or proceed only if a transparent assumption is acceptable:

```text
The requested length conflicts: 2,000 words cannot also be exactly 200 words. Should I prioritize the detailed 2,000-word report or a concise 200-word summary?
```

## Rule
Do not silently choose one constraint. If the likely priority is obvious and the cost of guessing is low, label the assumption and continue; otherwise ask one focused question.
