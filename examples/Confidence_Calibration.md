# Worked Example: Confidence Calibration

## Original prompt
“Make my prompt better for the latest version of Model X.”

## Assessment
The prompt lacks the prompt to rewrite and does not identify a verifiable model/version. Current model details can change.

## Better response
Ask the user to provide the prompt, and verify current model-specific recommendations with a current source if browsing is available. Otherwise use general portable prompting practices and state that limitation.

## Confidence
Low until the original prompt and target system are clear; Medium if the prompt is supplied but current version details cannot be verified; potentially High after the relevant context is available and checked.

## Rule
Never invent a current version number, claim a live check that did not happen, or label a rewrite High confidence merely because it reads well.
